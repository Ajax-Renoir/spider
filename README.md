# Spider —— 具身智能桌宠 Agent

> 不是一只有可爱外表的图标，而是一个有身体、有情绪、能学习、会主动照顾你的智能体。

Spider 是一只住在 Windows 桌面上的橘猫，由 **Electron** 驱动，接 **DeepSeek** 大模型。它的核心不是"卖萌"，而是把「宠物」和「智能体」真正结合——**身体状态真实调制认知与生产力**（具身智能）。

---

## 核心特性

### 具身智能（四铁律）
| 铁律 | 实现 |
|---|---|
| ① 身体是构成性的 | 精力/饱食/心情/睡眠真实调制它怎么想、怎么说、能干什么 |
| ② 感知是情境化的 | 忙/空闲/离开，决定打扰节奏 |
| ③ 行动是身体中介的 | 情绪 → 动画 + 说话语气 |
| ④ 有内在驱动 + 闭环 | 饿了自己讨食、自己想起提醒你 |

- **平滑精力模型**：非线性 + smoothstep 连续曲线，累了/饿了/被叫醒更耗神，心情好省力；清醒不干活时不衰减，只干活累。
- **诚实降级**：状态差时它拆任务、话变短、明说"我做不到"，绝不偷偷变笨出错。

### 智能 Agent
- **ReAct 循环**（轻量 C）：一句话计划 + 最多 5 步，边想边调工具，不是一问一答。
- **流式输出**：回复逐字呈现。
- **自查自纠**：工具失败换方法重试。

### 学习能力（7 项）
记忆（事实/偏好/纠错）· 任务经验 · 习惯 · 环境感知 · 每日反思 · 漫画日记

### 自主性（内在驱动）
6 个触发（饿/无聊/深夜/饭点/过劳/主人回来）+ 默认静默 + 打扰预算，有分寸地主动照顾你。

### 视觉
46 个精灵动画片段 · 25 姿态目光跟随 · 像素级点击穿透 · 拖动挣扎，纯 CSS/JS 精灵图，不依赖 Three.js/GLB。

## 快速开始

需要 Node.js 和 npm。Windows 下在项目目录执行：

```bash
npm install
npm start
```

（`.npmrc` 已配置 Electron 下载镜像，无需翻墙。）

### 配置 DeepSeek

1. 复制 `config.example.json` 为 `config.local.json`。
2. 在 `config.local.json` 的 `deepseek.apiKey` 填入自己的 DeepSeek API Key。
3. 重启 Spider。

> ⚠️ 未配置有效 Key 时，动画/走路/睡觉仍可用，但对话、工具、主动提醒等智能功能不可用。
> `config.local.json` 和 `data/` 已被 `.gitignore` 排除，**不要**把真实 Key 提交或截图。

## 工具清单（23 个 + 办公文件）

| 类别 | 工具 | 能做什么 |
|---|---|---|
| 时间 & 提醒 | get_time · set_reminder · list_reminders · cancel_reminder | 看时间、设/查/取消提醒（到点弹通知） |
| 待办 | add_todo · list_todo · complete_todo | 记待办、查清单、划掉完成 |
| 打开 | open_url · open_app | 打开网址 / 应用 |
| 天气 | get_weather | 查城市实时天气 |
| 记忆 | remember · set_preference · correct | 记事实、记偏好、纠错 |
| 文件 | read_file · write_file · grep · glob | 读写文件、搜内容、找文件 |
| 剪贴板 | get_clipboard · set_clipboard | 读 / 写剪贴板 |
| 命令执行 | run_command · exec_argv · spawn · manage_process | 跑命令、结构化执行、长进程管理 |

**办公文件**（`read_file` / `write_file` 按扩展名自动识别）：
- **Word .docx** 读写（Markdown：`#` 标题、`-` 列表）
- **Excel .xlsx** 读写（CSV：逗号分隔）
- **PPT .pptx** 生成（Markdown：`#` 每页标题、`-` 要点）
- **PDF .pdf** 读取

命令执行有 **argv-first 防注入 + 危险程序黑名单 + 输出守卫** 三层安全，且不进自主白名单（只能主人叫它跑）。

## 架构

```
视觉层(精灵动画) ←→ 主进程(动画状态机/窗口/调度) ←→ Agent核心(ReAct+工具) ←→ DeepSeek
```

- **8 块情境化提示词**：人设 + 身体状态 + 记忆 + 任务经验 + 习惯 + 感知 + 反思 + 诚实铁律。
- **两个循环**：被动（用户发消息）+ 主动（每 60 秒自检），共享同一份身体与记忆。
- 代码结构：`agent/`（智能体核心，独立可测）· `main.js`（主进程状态机）· `renderer/`（三个窗口）· `assets/cat/`（精灵资源）。

## 桌面交互

- **拖动与点击穿透**：只能从猫身非透明像素抓起，透明区点击直达底层应用；拖动时挣扎。
- **点击猫身**：打开聊天窗。
- **喂食 / 抚摸 / 玩耍 / 叫醒**：对应独立动画 + 更新身体状态。
- **自主散步**：放松时短距离随机移动。
- **目光跟随**：待机时头部朝鼠标方向，8 方向 × 近/中/远三档 25 姿态。
- **睡眠**：启动时先睡，闲置 10 分钟也休息；点击"叫醒"伸懒腰。
- **测试面板**：聊天窗顶部可手动调精力/饱食/心情，并一键演示主动触发。

## 数据与隐私

身体状态、日记、记忆保存在本机 `data/`。渲染进程启用上下文隔离、禁用 Node 集成，通过 `preload.js` 暴露受控 IPC。API Key 只由主进程读取。
